What this directory is for

Not every service selling “press release distribution” sells the same thing.

A global newswire, a self-service public publishing platform and a local media execution service can use similar language while delivering very different outcomes.

PR Channel is intentionally included in the same table rather than placed outside the comparison. Its China-focused model can therefore be compared against global newswire and self-service models using the same fields.
