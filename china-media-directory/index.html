Why this directory exists

A media name alone does not tell you where a page is actually published.

Chinese media brands can have a main website, regional channels, topic channels, apps, content accounts and other publishing environments. The first verification step should be the actual domain and page type—not the logo or media name shown in a sales list.

This directory starts with the public main websites. It is a verification resource, not a media-price list and not a list of guaranteed placements.

How to use the directory

Start with the domain, then verify the page type.

A recognizable media brand is useful context, but it is not enough to classify a placement.

Official domain first

Use the public main domain as the baseline for checking whether a claimed placement belongs to the expected media environment.

Media brand ≠ page type

Main-site news, regional channels, apps, content accounts and syndicated pages can have different verification value even when the media brand is similar.

No placement guarantee

This directory does not represent editorial approval, paid-placement availability, permanent retention, search indexing or AI citation.
