Second-layer verification

The same media name can lead to very different publishing environments.

The first layer verifies the official public domain. The second layer records whether the media also operates regional or vertical channels, mobile clients, creator/content-account platforms, video products or other public environments.

This matters because a page on an official main website should not automatically be treated as equivalent to an app page, content-account page, self-media channel or syndicated environment simply because the brand name looks familiar.

Classification rule

Brand name first tells you who it is. Page environment tells you what you actually received.

Use the directory as a starting point, then classify the exact URL in a placement report.

Main website

An article on the media's official public domain and normal editorial channel. This is the baseline environment the directory records first.

App / client

A mobile-client environment can be official but may have different URLs, visibility, persistence and public verifiability from the desktop website.

Creator / content account

Platforms such as creator accounts or self-media channels should be classified separately from the media brand's newsroom pages.

Other environments

Video products, databases, forums, mini programs and syndicated pages can be legitimate products while still representing a different placement type.
