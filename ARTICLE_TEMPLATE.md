# New article template

Create a new file inside `_posts/` using this filename format:

`YYYY-MM-DD-short-english-slug.md`

Paste this at the top:

```yaml
---
title: "Your Article Title"
description: "One clear sentence explaining what this article answers."
date: 2026-10-10
author: Yang Xiaole
category: Press Release Distribution
tags:
  - China Media
  - Press Release Distribution
---
```

Allowed core categories used by the guide page:

- `Press Release Distribution`
- `Media Placement`
- `Media Invitation`
- `AI & GEO`

Then write the article in Markdown:

```markdown
Opening answer in 1–3 paragraphs.

## First section

Content.

## Second section

Content.

## Practical conclusion

End with a useful distinction, checklist or decision rule.
```

After committing the file to `main`, GitHub Pages rebuilds the site. The new article automatically appears on the homepage latest-guides area, the China Media Guide, related-article blocks, and the XML sitemap.
