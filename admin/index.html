One secure login step remains

The CMS files are installed. To enable GitHub-backed publishing, create a free Decap Turbo site and paste its Site ID into admin/config.yml.

1
Create a Decap Turbo account and organization.
2
Connect GitHub and grant the Decap Turbo GitHub App access only to PRChannel/pressreleasechannel.com.
3
Create a site for this repository, branch main, config path admin/config.yml, admin URL https://pressreleasechannel.com/admin/.
4
Copy the Site ID and replace REPLACE_WITH_YOUR_DECAP_TURBO_SITE_ID in admin/config.yml.
Security: your GitHub password is never stored in this repository or in the CMS page. Authentication is handled by GitHub/Decap; do not paste a GitHub password, personal access token, client secret or API key into this repository.
